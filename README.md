# NusaQu Developer Theme

Modern news portal WordPress theme for the NusaQu AI Content Platform.

## Features

- 🎨 Modern, clean design with dark header and light content area
- 📱 Fully responsive (mobile-first approach)
- ✨ Smooth scroll animations with IntersectionObserver
- 🚀 Performance optimized (no jQuery dependency)
- 🎯 SEO-friendly markup
- 📖 Reading progress bar on single posts
- 🏷️ Category badges with gradient styling
- 📰 Featured hero post on homepage
- 🔍 Custom search page
- 💬 Styled comments section
- 🧩 Widget areas (sidebar + 3 footer columns)
- ♿ Accessible (ARIA labels, keyboard navigation, reduced motion support)

## Color Palette

| Color | Hex | Usage |
|-------|-----|-------|
| Primary Blue | `#2563EB` | Links, buttons, accents |
| Primary Dark | `#1D4ED8` | Hover states |
| Accent Purple | `#7C3AED` | Gradients |
| Dark BG | `#0f172a` | Header, footer |
| Light BG | `#f8fafc` | Content area |

## Installation

1. Download or clone this repository
2. Upload to `wp-content/themes/nusaqu-developer-theme`
3. Activate from Appearance → Themes

## Requirements

- WordPress 6.0+
- PHP 7.4+
